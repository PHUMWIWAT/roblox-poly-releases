# Roblox Poly

Turn a prompt or a picture into a Roblox model — straight into Studio.

Roblox Poly is a Windows desktop app that creates and edits 3D models in your open Roblox Studio:

- **Generate** a model from a text prompt or an image.
- **Edit in Studio** — re-texture, recolor, split meshes, add effects, turn a model into a tool or a pet.
- **Rig & animate** — bring a rigged `.glb` in with its bones and motions.
- **Export** to GLB or OBJ.

## Download

Get the latest Windows installer from the [**latest release**](https://github.com/PHUMWIWAT/roblox-poly-releases/releases/latest).

The installer is per-user — no admin rights needed. After installing, the app keeps itself up to date automatically.

## Requirements

- Windows 10/11
- Roblox Studio (with the **CreateAssetAsync Lua API** beta feature on, for rigging)
- A Roblox Poly account — sign in from the app's Account page
